# Changelog

## Unreleased

- Qualified the installed artifact against native-free Framework and same-version
  Console with concurrent publication, live deadlines/cancellation, late physical
  return/resource ownership, diagnostic faults and mixed-mission accounting checks.
- Added actual Console/browser/MCP import, bounded query and content-read checks,
  plus exact local build evidence and repeatable inspection instructions.
- Native TypeSafe declarations/connections and generated output metadata have been
  removed from Framework. Use ordinary executor YAML and full `/answers/...` paths.
  Validation occurs at invocation; executor-config decimals use ordinary decoding.
  Applications supply resolved credentials. Pack requests/retries do not consume
  Framework provider-attempt quota or contribute to Framework-accounted usage;
  missing provider usage stays absent. Cancellation is cooperative, without native
  physical-cancellation/accounting parity. No compatibility adapters are supplied.

- Added reference-only TypeSafe executor with native Choice/Noul/Score request
  validation, explicit JSON Pointer input bindings and complete JSON results.
- Added an independent installed-JAR consumer, runnable support-triage recipe,
  composition/binding checks and normal canonical diagnostic evidence.
- Established the independent Maven descriptor and code/test/example locations.
- Added TypeSafe transport with captured settings, shared Spring-managed connections,
  bounded retries/total deadlines, complete JSON responses and invocation diagnostics.
- Added deterministic local HTTP, lifecycle, shutdown and resource-boundary tests,
  plus dated primary provider documentation and synthetic wire fixtures.
